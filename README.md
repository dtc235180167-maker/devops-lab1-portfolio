## Các công việc đã thực hiện
1. Khởi tạo Repository trên GitHub và đồng bộ về máy cục bộ.
2. Xây dựng trang web tĩnh cá nhân bằng HTML/CSS (`index.html`).
3. Cấu hình quy trình CI/CD tự động bằng GitHub Actions (`.github/workflows/deploy.yml`).
4. Tự động kiểm tra và triển khai (Deploy) trang web lên GitHub Pages khi push code lên nhánh `main`.
